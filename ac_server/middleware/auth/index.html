ac_server::middleware

Module auth 

Source
Expand description

Request authentication middleware for protected routes.

Verifies the Ed25519 request signature (§10-11) and binds the verified agent id to the request as an AuthenticatedAgent extension. Handlers must take the caller’s identity from that extension, never from the body, the query string or the X-Agent-Id header.

Checks, in this order (cheap and side-effect free first):

  1. credentials present (X-Agent-Id, -Timestamp, -Nonce, -Signature)
  2. timestamp is RFC 3339 and within ±MAX_TIMESTAMP_SKEW_SECS
  3. body is at most MAX_BODY_BYTES and is buffered for hashing
  4. agent exists and is REGISTERED or ACTIVE
  5. signature verifies over agent_id \n timestamp \n nonce \n method \n path_and_query \n sha256(body)
  6. nonce is consumed (single use), only after the signature verified, so an unauthenticated caller cannot burn another agent’s nonces

Failure mapping: 401 missing credentials or failed authentication, 400 malformed, stale or replayed credentials, 413 oversized body, 503 when the database is unavailable (fail closed).
