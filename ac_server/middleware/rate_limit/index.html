Module rate_limit 

Source
Expand description

Global and per-agent rate limiting middleware.

  • rate_limit is the outermost guard. It applies the global bucket to every request and never looks at client-supplied identity.
  • rate_limit_agent applies the per-agent bucket. It must run behind the authentication layer and keys on the verified AuthenticatedAgent, so a caller cannot drain another agent’s allowance by naming it in X-Agent-Id, and cannot mint fresh allowances by rotating fake ids.
