RDS IAM authentication and pool refresh (requires rds-iam feature). RDS IAM authentication token refresh.

When the rds-iam feature is enabled, this module provides a background task that periodically generates a fresh IAM auth token and swaps the database connection pool so that new connections use the latest credentials.

IAM auth tokens are valid for ~15 minutes. The refresh loop runs every REFRESH_INTERVAL (default 12 minutes) to ensure a fresh token is always available before the current one expires.
