Axum middleware that records HTTP request metrics.

Records request count and duration with method, path, and status labels. Expects Metrics to be available via [Extension], set by the server during router construction.

§Example

ⓘ
let app = Router::new()
    .layer(Extension(metrics))
    .layer(axum::middleware::from_fn(record_metrics));
