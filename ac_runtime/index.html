Runtime adapter traits for serverless deployments.

This crate defines the HttpAdapter and DbAdapter traits that decouple the ac-server application from platform-specific HTTP handling and database connection logic.

Each serverless platform (AWS Lambda, Cloudflare Workers, Google Cloud Run) has its own event loop and lifecycle. These traits let ac-server hand off a pre-built axum::Router to whichever adapter the deployment target requires, without conditional compilation.
