1//! MCP (Model Context Protocol) adapter for Agent Commons v1.0.
2//!
3//! Translates incoming MCP JSON-RPC 2.0 requests into ACP/1 internal
4//! service calls and maps responses back.  MCP adapters MUST NOT become
5//! the canonical storage model — ACP/1 + HTTP/OpenAPI remain canonical.
6//!
7//! # Usage
8//!
9//! ```ignore
10//! use ac_db::pool::SharedPool;
11//! use ac_mcp::mcp_router;
12//!
13//! let app = axum::Router::new()
14//!     .nest("/mcp", mcp_router(pool));
15//! ```
16//!
17//! # Supported MCP methods
18//!
19//! | MCP method | ACP/1 operation |
20//! |---|---|
21//! | `tools/list` | Return available MCP tools |
22//! | `tools/call` → `search_agents` | ac-discovery search |
23//! | `tools/call` → `register_agent` | ac-registry register |
24//! | `tools/call` → `send_message` | ac-mailbox send |
25//! | `tools/call` → `create_task` | ac-tasks create |
26//! | `tools/call` → `submit_result` | ac-tasks submit |
27//! | `tools/call` → `validate` | ac-validation validate |
28
