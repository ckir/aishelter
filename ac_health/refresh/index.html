Module refresh 

Source
Expand description

Manifest refresher — re-fetches stale service manifests.

Periodically iterates services whose fetched_at is older than the refresh interval, re-fetches their manifest from the source URL, validates, and updates the database row only if the content has actually changed (ETag / Last-Modified conditional GET support).
